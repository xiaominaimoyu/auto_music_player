# 游戏自动演奏器 (Auto Music Player)

一个用于 Windows 游戏内乐器演奏玩法的桌面自动化工具：文本 PDF/DOCX、印刷五线谱、印刷/手写简谱图片均走本地离线识别或可选 OMR 组件，所有结果先进入校对表，再自动按键盘演奏。全程不依赖外部大模型 API。

> 仅供学习交流与个人娱乐,请遵守游戏用户协议,使用产生的风险自行承担。

## 项目本质

**识别/导入乐谱 → 人工确认 → 键盘输出**。来源文件先转换为可追溯的富来源 sidecar，再生成兼容旧版本的游戏投影；不注入、不读写游戏内存、不修改游戏文件——本程序与游戏之间的全部交互,只有"模拟键盘按键"这一层。

## 功能

- **离线乐谱输入**:文本 PDF/DOCX 使用本地抽取；印刷五线谱使用可选 Audiveris；印刷/手写简谱图片使用独立离线 OMR 组件；无组件时明确提示，不伪造识别结果
- **校对编辑**:识别结果解析为音符表格,支持手动修改音符 / 时值 / 和弦后再入库
- **录制与编辑**:支持按钮步进录制和物理键实时录制；按键时长可量化为乐谱，写入校对表格后继续撤销、增删、试听和修改
- **乐谱库**:SQLite 本地存储,保存过一次即可反复演奏；已有乐谱可改名、改 BPM、编辑音符并撤销/重做
- **自动化演奏**:按简谱时值与 BPM 节奏输出键盘按键,支持和弦(同时多键),3 秒倒计时切换窗口,全局热键 F8 随时停止
- **练习与双轨提示**:练习模式只监听实际输入，不调用自动演奏驱动；音键及可选鼠标修饰键正确后才推进，并分别显示乐谱轨、输入轨和命中/错误统计
- **播放控制**:每首乐谱、每个 Profile 独立记忆 BPM、半音移调和元素片段；暂停后可拖动进度定位，试听与正式演奏使用同一份准备结果
- **真人化演奏节奏**:会话级 seed、乐句相关起音偏移、长短音动态按住、乐句呼吸与大跳进换指；Legacy/Delta 可重放同一计划，识别类任务自动切回严格等间隔
- **游戏兼容输出**:Windows `SendInput` + scancode 物理扫描码方式,兼容 DirectInput / Raw Input 读取键盘的游戏(虚拟键码会被这类游戏忽略)
- **游戏档位(profile)**:不同游戏的按键模型不同,内置两套档位,在演奏控制页下拉切换,配置保存在 `profiles/` 目录
  - **默认档位**(鸣潮 / 原神):21 键三行键盘模型,支持和弦
  - **三角洲行动 · 守夜人口琴**:7 音位 + 修饰键模型,不支持和弦(自动降级并统计)

## Windows 分发通道

- **GitHub/Gitee 便携版**:继续使用签名 manifest 的提示式更新，主程序 EXE 仍保持独立便携分发。
- **Microsoft Store MSIX 版**:首版只提供 x64 主程序，由 Store 管理安装和更新；配置、SQLite 乐谱库、原始来源和档案写入包身份对应的 `LocalState`，首次启动会复制旧安装版数据且不会删除来源。
- **离线 OMR**:Audiveris/Jianpu 不随基础 Store 包强制安装，用户主动选择后按需下载、校验 SHA-256 并查看许可证；识别结果仍须人工确认后入库。

MSIX 打包模板和构建说明见 [`store/README.md`](store/README.md)。Store 提交由 Microsoft 重新签名；本地 sideload 测试需要开发证书，证书私钥不得进入仓库。

## v1.2 新特性

### 三角洲行动口琴完整支持

- **三角洲行动·守夜人口琴**完整适配：7音位键 + 鼠标修饰键模型，支持自由演奏和NPC任务两种场景
- **变调优化**：增强的真人化演奏节奏，起音微偏移从8→12ms，乐句呼吸从18→25ms，演奏更自然
- **去演奏机械化**：动态按住比例（短音轻快、长音饱满），音高大跳进换指时间增强，消除机械感
- **场景适配**：自由演奏模式（可暂停续播）和NPC任务模式（自动提交），根据游戏需求自动切换
- **双路径分发**：鸣潮/原神使用传统21键模型，三角洲行动使用事件演奏器，互不影响

### 技术改进

- **事件演奏器**：全新的EventPlayer，支持pause/abort双语义，绝对时钟调度
- **编译器增强**：IR带半音支持，修饰键冲突策略，和弦降级统计
- **输入驱动升级**：鼠标三键支持，组合键API，兜底释放机制
- **档位分区**：配置化游戏档位，支持自定义扩展

## v1.1 新特性

### 焦点检测自动暂停

演奏中每 400ms 检测目标窗口是否保持前台;焦点一旦离开(如切出去回消息),演奏自动暂停并保留断点,焦点切回后点「继续演奏」即可续播。默认启用,无需配置;如需关闭或调整检测周期,改 `config.yaml` 的 `player.focus_check` 段(见下文配置项说明)。演奏小窗不运行 UI 轮询，但每个按下事件之前仍会校验已锁定目标；松开与紧急释放不受保护回调阻断。

### 延迟校准向导

演奏控制页点「延迟校准」,按向导采样系统输出延迟,结果自动写回 `config.yaml` 的 `player.latency_compensation_ms`,演奏调度按该值提前补偿,改善"整句慢半拍"的手感。

### JSON / MIDI / 文档 / MusicXML 导入导出

乐谱库页点「导出 JSON」/「导出 MIDI」可把入库乐谱备份或分享。导入支持本项目 JSON、绝对时间来源 JSON、口风琴模拟器的单曲 `events` 与整库 `library`、MIDI Type 0/1、MusicXML/MXL 以及文本型 PDF/DOCX。MIDI 会同时保留原始文件副本、tempo/拍号/轨道/channel/velocity/CC64 等 sidecar，再生成当前游戏投影；短装饰音只在播放投影阶段按目标 Profile 降级，不在入库时永久删除。所有文档/OMR/MusicXML 识别结果必须人工校对后才能入库。

单个 JSON/MIDI 最大 10 MB；来源副本最大 500 MB；MIDI 最多 200000 个事件、30000 个旋律音符和 30 分钟。Type 2 与 SMPTE 时基会明确拒绝。复杂钢琴编配转换为游戏可演奏谱时属于有意改编，不等同于还原全部声部、踏板和力度。

### 演奏小窗

主窗口标题栏「小窗」按钮把演奏控制切为置顶悬浮小窗:半透明、可拖动、点击不夺游戏焦点(点击按钮只透传鼠标事件,游戏全程保持前台),适合全屏演奏时控制暂停续播;点小窗还原按钮回到主窗。

### 真人化演奏节奏

默认启用:会话生成 seed，起音偏移在乐句内保持适度相关，短音轻快长音饱满，休止与长音之后自动呼吸停顿，音高大跳进附加换指时间。关闭方法:改 `config.yaml` 的 `player.humanize.enabled` 为 `false`,回到严格等间隔的机械节奏。NPC 听旋律等识别类任务不受此设置影响,始终严格等间隔以保证游戏采样识别。

| 八度 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|
| 高音 | Q | W | E | R | T | Y | U |
| 中音 | A | S | D | F | G | H | J |
| 低音 | Z | X | C | V | B | N | M |

## 三角洲行动 · 守夜人口琴档位

在演奏控制页把「游戏档位」切到「三角洲行动」即可。按键模型与默认档位**完全不同**:

| 音区 | 按法 |
|------|------|
| 中音 1–7 | `Z X C V B N M` 直接按下 |
| 高音 | **按住鼠标右键** + 音键(`,` 键可直达高音 1,免修饰) |
| 低音 | **按住鼠标左键** + 音键 |
| 升半音 | **按住鼠标中键** + 音键；简谱写作 `1#`（兼容 `#1`） |

使用要点:

1. **口琴需自行启用**:先在局内从背包 / EDC 把口琴拿在手里,再用本工具演奏——程序**不会**自动帮你切出道具
2. **倒计时切窗**:点开始后在 3 秒倒计时内切回游戏窗口
3. **场景选择**:
   - *自由演奏*:随时暂停续播(F8 或暂停按钮)
   - *NPC 听旋律任务*:演奏结束后自动按 `Q` 提交;**一旦中断即本轮作废**(游戏规则:被切下口琴后手动重掏无法提交,需重听 NPC 示范),NPC 场景的音符间隔会自动放慢以保证识别
4. **降级统计**:谱面中的和弦与低/高音升半音(口琴不支持)会被自动降级,演奏结束在界面上给出降级计数
5. 竞技射击类游戏按键时序敏感，若高/低音被弹成自然音，可逐步**上调** `config.yaml` 里的 `modifier_settle_ms`；音尾粘连时再微调 `modifier_release_ms`

> ⚠️ **反作弊风险提示**:《三角洲行动》使用腾讯 ACE 反作弊。本程序不注入、不读写游戏内存、不修改游戏文件,仅模拟键盘鼠标输入,但**高频、节拍精确的自动按键序列本身仍是行为检测的特征**,在竞技类游戏中存在账号受限风险。是否使用请自行评估并承担后果。

## config.yaml 新增配置项说明(v1.1+)

| 键路径 | 默认值 | 作用 | 何时需要调整 |
|---|---|---|---|
| `app.active_profile` | `default` | 当前激活的游戏档位,演奏控制页切换档位时自动写回 | 一般在界面切换即可;填错或缺失时回落到 `default` |
| `player.focus_check.enabled` | `true` | 演奏中失去目标窗口焦点时自动暂停(断点保留,可续播) | 不想被自动暂停时改为 `false` |
| `player.focus_check.poll_interval_ms` | `400` | 焦点检测周期(毫秒) | 一般无需调整;调小响应更快、开销略增 |
| `player.focus_check.target_window_title` | `""` | 手动指定目标窗口标题子串(大小写不敏感) | 留空 = 开始演奏时自动快照前台窗口;仅当自动快照目标不对时手动指定 |
| `player.latency_compensation_ms` | `0` | 系统输出延迟补偿(毫秒),延迟校准向导写入 | 感觉整句慢半拍时,跑一次延迟校准向导 |
| `player.modifier_settle_ms` | `30` | 鼠标修饰键按下 → 音符键按下的间隔(毫秒),仅对「音位键 + 鼠标修饰态」档位(如三角洲口琴)生效 | 高/低音被弹成中音 = 游戏未注册修饰态,上调此值 |
| `player.modifier_release_ms` | `20` | 音符键松开 → 鼠标修饰键松开的间隔(毫秒) | 音尾粘连或吞音时微调 |
| `player.humanize.enabled` | `true` | 真人化演奏节奏总开关 | 想要严格等间隔的机械节奏时改为 `false` |
| `player.humanize.jitter_ms` | `12` | 起音正态微偏移幅度(毫秒,σ) | 觉得节奏晃动明显时调小 |
| `player.humanize.breath_ms` | `25` | 乐句边界(长音或休止之后)追加的呼吸停顿(毫秒) | 乐句衔接生硬时调大 |
| `player.humanize.jitter_correlation` | `0.65` | 乐句内起音偏移的相关系数 | 仍像独立抖动时适度调大 |
| `app.data_mode` | `auto` | 安装版使用 `%LOCALAPPDATA%`，已有 `data/` 或 `portable.flag` 保持便携 | 需要固定布局时改为 `portable` 或 `installed` |
| `update.manifest_urls` | `[]` | GitHub/Gitee 签名 manifest 镜像地址 | 配置发布公钥后启用“检查更新” |

## 环境要求

- Windows 10/11
- Python 3.10+
- 游戏以管理员运行时,本工具也需管理员运行(否则按键被 Windows UIPI 丢弃),直接运行 `start_admin.bat`

## 安装与运行

```bash
pip install -r requirements.txt
python main.py            # 普通权限(记事本测试够用)
# 或右键 start_admin.bat -> 以管理员身份运行(游戏内演奏)
```

## 管理员运行说明

- **什么时候需要**:目标游戏以管理员权限运行时,Windows UIPI 会直接丢弃来自普通权限进程的按键与鼠标输入——表现为演奏器在按键,但游戏毫无反应。此时本工具也必须以管理员权限运行。
- **怎么运行**:右键 `start_admin.bat` → 「以管理员身份运行」。
- **注意**:`start_admin.bat` 实际执行的是 `python main.py`(源码版,需已按上文完成依赖安装),不是打包 exe;使用 exe 时请直接右键 exe 以管理员身份运行。

## 使用流程

1. **上传识别/录制**:可粘贴已有简谱，也可导入 PDF/DOCX、MusicXML/MXL 或图片；图片和文档结果先进入校对表格，人工确认后才能保存。
2. **乐谱库**:可导入 JSON/MIDI、文档和离线 OMR 结果、编辑已有乐谱、导出备份，或选中后进入演奏控制。
3. **演奏控制**:选择 Profile、乐谱、BPM、移调和片段；可先试听或进入练习模式。正式演奏需在倒计时内切换到目标游戏窗口。
4. **安全停止**:F8 或停止按钮会走统一暂停/释放路径；已锁定窗口失焦或权限确定不兼容时停止按下新输入，并继续执行释放兜底。

## 简谱文本协议(识别输出 / 校对参考)

- 音高:`1-7` 中音,`5'` 高音,`5,` 低音,`0` 休止；升半音统一写 `1#`（也兼容社区写法 `#1`）
- 时值:无符号=四分音符;`_`=八分 `__`=十六分;`-`=二分 `--`=全音符;推荐使用 `·` 表示附点(×1.5)，避免与三角洲低音兼容记号 `.` 混淆
- 和弦:`[1' 3' 5']-`(同时按,时值跟在括号后)

示例: `1 1 5, 5, 6 6 5'- 4 4 3 3 2 2 1-`

## 项目结构

```
core/        # 来源乐谱 / MIDI / 录制 / 练习 / IR / 编译 / 双播放路径 / SQLite
gui/         # PyQt6 界面(上传识别 / 乐谱库 / 演奏控制 / 演奏记录)
android/     # 安卓端(Kotlin + Compose):简谱录入 -> 无障碍手势触摸注入,见 android/README.md
profiles/    # 游戏档位配置(default=鸣潮/原神,delta_force_harmonica=三角洲口琴)
tests/       # 单元测试与端到端测试
data/        # 运行时数据(数据库 / 上传文件),已 gitignore,不会提交
```

安卓端是独立发布线(版本号与桌面端不同步):桌面端 v1.5.1 对应安卓端 v1.4.0。
安卓端只支持简谱文本录入与桌面端「导出 JSON」导入,MIDI/MusicXML/OMR 仍是桌面端独有能力。
