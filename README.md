# 游戏自动演奏器 (Auto Music Player)

一个用于《鸣潮》《原神》等游戏内乐器演奏玩法的桌面自动化工具:上传乐谱(图片/文档)→ 大模型识别提取简谱 → 校对 → 自动按键盘演奏。

> 仅供学习交流与个人娱乐,请遵守游戏用户协议,使用产生的风险自行承担。

## 项目本质

**识别乐谱 → 键盘输出**。把乐谱(图片/文档)识别为结构化音符序列,再按节奏把音符映射为键盘按键输出,仅此而已。不注入、不读写游戏内存、不修改游戏文件——本程序与游戏之间的全部交互,只有"模拟键盘按键"这一层。

## 功能

- **乐谱识别**:调用多模态大模型(OpenAI 兼容接口,通义千问 / GLM / Kimi / OpenAI 等均可)识别乐谱图片或文档,输出规范化简谱;也可点「复制提示词」交给任意外部 AI 工具识别,把简谱粘贴到识别结果直接解析,无需 API Key;内置样例识别器可离线跑通流程
- **校对编辑**:识别结果解析为音符表格,支持手动修改音符 / 时值 / 和弦后再入库
- **乐谱库**:SQLite 本地存储,保存过一次即可反复演奏,无需重新上传
- **自动化演奏**:按简谱时值与 BPM 节奏输出键盘按键,支持和弦(同时多键),3 秒倒计时切换窗口,全局热键 F8 随时停止
- **游戏兼容输出**:Windows `SendInput` + scancode 物理扫描码方式,兼容 DirectInput / Raw Input 读取键盘的游戏(虚拟键码会被这类游戏忽略)

## 按键映射(可在 `config.yaml` 修改)

| 八度 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|
| 高音 | Q | W | E | R | T | Y | U |
| 中音 | A | S | D | F | G | H | J |
| 低音 | Z | X | C | V | B | N | M |

## 环境要求

- Windows 10/11
- Python 3.10+
- 游戏以管理员运行时,本工具也需管理员运行(否则按键被 Windows UIPI 丢弃),直接运行 `start_admin.bat`

## 安装与运行

```bash
pip install -r requirements.txt
python main.py            # 普通权限(记事本测试够用)
# 或右键 start_admin.bat -> 以管理员身份运行(游戏内演奏)
```

## 使用流程

1. **模型设置**(可选):添加自定义供应商(名称 / Base URL / API Key / 模型名称,需为支持图片输入的多模态模型)→ 测试连接 → 设为激活;不配置则使用内置样例
2. **上传识别**(两种途径任选):
   - 在线识别:拖入乐谱图(jpg/png/webp/bmp)或文档(md/txt/docx)→ 开始识别 → 解析到校对表格 → 保存入库
   - 外部 AI 识别(免 API Key):点「复制提示词」→ 粘贴到任意外部 AI 工具并附上乐谱图片 → 把返回的简谱粘贴到「识别结果」→ 解析到校对表格 → 保存入库
3. **演奏控制**:选择乐谱、调整 BPM → 开始演奏 → 倒计时 3 秒内切换到游戏窗口

## 简谱文本协议(识别输出 / 校对参考)

- 音高:`1-7` 中音,`5'` 高音,`5,` 低音,`0` 休止
- 时值:无符号=四分音符;`_`=八分 `__`=十六分;`-`=二分 `--`=全音符;`·` 附点(×1.5)
- 和弦:`[1' 3' 5']-`(同时按,时值跟在括号后)

示例: `1 1 5, 5, 6 6 5'- 4 4 3 3 2 2 1-`
