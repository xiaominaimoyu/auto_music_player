# 演奏节奏优化验证步骤

## 快速验证（5 分钟）

### 1. 启动程序
```bash
cd "D:\project file\auto_music_player"
python main.py
```

### 2. 测试真人化效果

**步骤 A：加载测试乐谱**
- 在 GUI 中选择任意简单曲目（建议有明显长短音对比的曲子）
- 点击"开始演奏"

**观察点**：
- ✅ 每个音符起音时刻有轻微随机偏移（不再完全等间隔）
- ✅ 短音（八分音符）明显短促，长音（全音符）明显绵延
- ✅ 休止符后、长音后有微妙停顿（呼吸感）
- ✅ 大跳进（如 C→高音 C）之间有短暂迟疑（换指感）

### 3. 对比测试

**步骤 B：关闭真人化**
1. 关闭程序
2. 编辑 `config.yaml`，设置：
   ```yaml
   player:
     humanize:
       enabled: false
   ```
3. 重启程序，演奏同一乐谱

**观察点**：
- ⚠️ 节奏变回完全等间隔（机械感明显）
- ⚠️ 所有音符按住时长统一（无长短对比）
- ⚠️ 无呼吸停顿，无换指感

**步骤 C：恢复真人化**
1. 再次编辑 `config.yaml`，设置 `enabled: true`
2. 重启验证自然节奏恢复

## 常见问题排查

### 问题 1：听不出真人化效果

**原因**：
- 可能选择的曲目节奏单一（全部四分音符）
- 参数过于保守

**解决**：
- 选择有明显长短音对比的曲目（如《小星星》《欢乐颂》）
- 临时调大参数测试：`jitter_ms: 20, breath_ms: 40`

### 问题 2：节奏听起来混乱

**原因**：
- 参数过大

**解决**：
- 调小参数：`jitter_ms: 8, breath_ms: 15`
- 或关闭真人化：`enabled: false`

### 问题 3：某些音符叠键/冲突

**原因**：
- 极少数边界 case 未覆盖（理论上已完全防护）

**解决**：
- 调大最小间隙：`min_gap_ms: 2.0`（需修改 `core/humanize.py` 默认值）
- 提交 issue 报告具体乐谱

### 问题 4：NPC 识别任务仍有抖动

**原因**：
- 场景检测未生效

**解决**：
- 检查 `scenario.py` 中 `NpcQuestScenario.humanize` 是否为 `False`
- 确认使用的是三角洲档位（delta profile）
