# 休止符使用指南

## 快速开始

休止符功能已在 **Windows 桌面端和安卓端** 完整实现,本指南帮助你快速上手。

---

## 一、基本用法

### 1.1 简谱标记

在简谱中使用数字 `0` 表示休止符:

```
1 2 3 0 5 6 7
    ↑
   休止符
```

### 1.2 时值标记

| 标记 | 时值 | 名称 |
|------|------|------|
| `0` | 1拍 | 四分休止符 |
| `0_` | 0.5拍 | 八分休止符 |
| `0__` | 0.25拍 | 十六分休止符 |
| `0-` | 2拍 | 二分休止符 |
| `0--` | 4拍 | 全休止符 |
| `0.` 或 `0·` | 1.5拍 | 附点四分休止符 |

## 二、实战示例

### 2.1 小星星(带休止符)

```
1=C 4/4
1 1 5 5 | 6 6 5- | 0 0
4 4 3 3 | 2 2 1-
```

**效果**: 第3小节有两个四分休止符,形成明显停顿。

### 2.2 复杂节奏

```
1 0_ 2 3 0 5_ 6_ 0--
```

**说明**:
- `0_`: 短促停顿(八分休止)
- `0`: 正常停顿(四分休止)
- `0--`: 长时间停顿(全休止)

### 2.3 和弦与休止混排

```
[1 3 5]- 0 [2 4 6] 0_
```

**效果**: 和弦后的休止符让节奏更有层次感。

## 三、GUI 操作

### 3.1 录入步骤

1. **打开上传页**: 点击顶部"上传"标签
2. **输入简谱**: 在文本框中输入含 `0` 的简谱
3. **点击解析**: 点击"解析简谱"按钮
4. **查看结果**: 校对表格中休止符显示为 `(休止)`
5. **修改时值**: 可直接在"时值(拍)"列修改休止时长
6. **保存入库**: 点击"保存曲谱"

### 3.2 校对表格示例

| 音符 | 时值(拍) | 半音 |
|------|---------|------|
| mid_1 | 1.0 | |
| (休止) | 0.5 | |
| mid_2 | 1.0 | |

### 3.3 演奏测试

1. **进入演奏页**: 点击顶部"演奏"标签
2. **选择曲谱**: 从下拉列表选择刚才保存的曲谱
3. **点击播放**: 点击"开始演奏"按钮
4. **观察效果**: 休止符位置会有明显停顿,不按任何键

## 四、常见问题

### Q1: 休止符处理还在按键?

**A**: 检查简谱是否正确使用 `0`:
- ✅ 正确: `1 0 2`
- ❌ 错误: `1 O 2` (字母 O)
- ❌ 错误: `1 o 2` (小写 o)

### Q2: 休止时长不准确?

**A**: 确认以下设置:
1. **BPM**: 演奏页设置的 BPM 值
2. **时值后缀**: `0_` ≠ `0` ≠ `0-`
3. **真人化**: 如开启会有±50ms 随机偏移

### Q3: 休止符后音调错乱?

**A**: 这是旧版本 bug,已在 v1.1 修复。确保:
1. 使用最新版本
2. 休止符前的修饰键(高低八度)会自动释放

### Q4: 可以连续多个休止符吗?

**A**: 可以,例如:
```
1 0 0 0 2
```
等价于 3 拍连续停顿。

## 五、技巧提示

### 5.1 节奏型设计

**跳跃感**:
```
1 0_ 2 0_ 3 0_ 5
```

**呼吸感**:
```
1 2 3 4 | 5 6 7 0 | 1' 2' 3' 4'
              ↑
           换气点
```

### 5.2 时值搭配

| 组合 | 效果 |
|------|------|
| `5- 0` | 长音 + 停顿 = 庄重感 |
| `5 0_` | 短音 + 小停顿 = 轻快感 |
| `5_ 0__` | 快速音符间隙 |

### 5.3 外部 AI 识别

使用外部 AI(如 ChatGPT)识别乐谱时,提示词示例:

```
请将以下五线谱转换为简谱,使用数字0表示休止符,
注意附点用 · 标记,高音用 ' 标记,低音用 , 标记。
```

## 九、故障排除

### 问题: 解析失败

```
错误提示: "无法识别的内容"
```

**解决方案**:
1. 检查是否使用中文标点 `'` `，`(应使用英文)
2. 检查 `0` 是否为数字(不是字母 O)
3. 使用"collect 模式"查看详细错误:
   ```python
   notes, errors = parse_jianpu(text, collect=True)
   for e in errors:
       print(e)
   ```

### 问题: 演奏卡顿

**可能原因**:
1. BPM 设置过高(>200)
2. CPU 占用过高
3. 延迟补偿值过大(>100ms)

**解决方案**:
1. 降低 BPM
2. 关闭后台程序
3. 调整延迟补偿(默认 50ms)
