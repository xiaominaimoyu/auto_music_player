## 📝 使用示例

### 快速测试简谱

```
1=C 4/4
1 1 0 5 | 5 0 6 6 | 5- 0 0
```

**预期效果**: 第3、6、9、10位置有明显停顿。

### GUI 操作步骤

1. 打开程序: `python main.py`
2. 进入"上传"页
3. 粘贴上述简谱
4. 点击"解析简谱"
5. 校对表格中第3、6、9、10行显示 `(休止)`
6. 保存后进入"演奏"页播放
7. 验证休止符位置的停顿效果
