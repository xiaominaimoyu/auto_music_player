## 二、技术实现

### 2.1 数据结构定义

#### 核心 IR 类 (`core/ir.py:71-77`)

```python
@dataclass(frozen=True)
class IRRest:
    """休止符:表示演奏中的静默停顿。"""
    dur: float = 1.0  # 时值(拍)

    def __post_init__(self):
        if not 0 < float(self.dur) <= MAX_DUR_BEATS:
            raise ValueError(f"dur 必须在 (0, {MAX_DUR_BEATS}]: {self.dur}")
```

#### 存储格式

```json
{
  "notes": [],      // 空列表表示休止符
  "dur": 1.0        // 时值(拍)
}
```

### 2.2 完整数据流转

```
简谱文本 (0)
    ↓ parse_jianpu()
存储格式 {"notes": [], "dur": 1.0}
    ↓ from_storage()
IR 对象 IRRest(dur=1.0)
    ↓ compile_score()
时间间隔 (cursor += dur * beat_ms)
    ↓ Player/EventPlayer
实际停顿 (time.sleep() / Event.wait())
```

## 三、核心模块实现

### 3.1 解析器 (`core/parser.py`)

#### 支持的休止符标记

| 简谱记号 | 时值 | 说明 |
|---------|------|------|
| `0` | 1.0拍 | 四分休止符 |
| `0_` | 0.5拍 | 八分休止符 |
| `0__` | 0.25拍 | 十六分休止符 |
| `0-` | 2.0拍 | 二分休止符 |
| `0--` | 4.0拍 | 全休止符 |
| `0.` 或 `0·` | 1.5拍 | 附点四分休止符 |
| `0_·` | 0.75拍 | 附点八分休止符 |

#### 代码实现 (`parser.py:81-89`)

```python
def _build_single(token: str):
    """返回 (音符, 问题)。0 一律为休止;休止带八度记号记为问题,不影响输出。"""
    num = int(token[0])
    pitch, rest, semitone = _split_pitch_dur(token[1:])
    dur = _parse_dur(rest)
    problem = None
    if num == 0:
        if token[1:2] in ("'", ","):
            problem = "休止符 0 不应带八度记号"
        return {"notes": [], "dur": dur}, problem
```

### 3.2 编译器 (`core/compiler.py`)

#### 时间轴推进逻辑 (`compiler.py:236-242`)

```python
for i, item in enumerate(plan):
    if item["kind"] == "rest":
        # 释放当前按住的修饰键
        if held:
            result.events.append(InputEvent(cursor, "mouse", held, "up"))
            cursor += release_settle
            held = None
        # 推进时间轴,不产生任何按键事件
        cursor += item["dur"] * beat_ms + gap
        continue
```

**关键特性:**
1. **修饰键释放**:休止符前如有修饰键(如高八度)按住,会自动释放
2. **精确计时**:时值完全遵循 `dur * beat_ms`,不受 `hold_ratio` 影响
3. **无事件生成**:休止符不产生任何 `InputEvent`,纯时间推进

### 3.3 演奏引擎

#### Player (`core/player.py:158`)

```python
# 休止符:时值由下一音符的绝对开始点体现,无需单独等待
# cursor_s += dur_ms / 1000.0 + gap_s
```

**设计要点:**
- 采用**绝对时钟调度**:每个音符的起始时刻 = `t0 + Σ前置音符时值`
- 休止符不需要显式 `sleep()`,下一个音符的 `wait_s` 自动包含休止时长
- 精度保证:不受音符数累积误差影响

## 七、常见问题

### Q1: 休止符时长不准确?

**A:** 检查以下几点:
1. BPM 设置是否正确(影响拍长)
2. 是否开启真人化(会随机偏移,关闭方法见配置文件)
3. 延迟补偿值是否合理(默认 50ms)

### Q2: 休止符前的修饰键没有释放?

**A:** 这是已知并已修复的问题,确保使用 v1.1+ 版本:
```python
# core/compiler.py:236-242 包含修饰键释放逻辑
if held:
    result.events.append(InputEvent(cursor, "mouse", held, "up"))
```

### Q3: 如何区分休止符和空数据?

**A:** 通过 `notes` 字段区分:
- 休止符: `{"notes": [], "dur": 1.0}` (空列表 + 有效时值)
- 空数据: `{}` 或 `null` (会被 Schema 校验器拒绝)

### Q4: 连续多个休止符会合并吗?

**A:** **不会合并**,保持独立:
```python
parse_jianpu("0 0 0")
# → [{"notes": [], "dur": 1.0}, 
#    {"notes": [], "dur": 1.0}, 
#    {"notes": [], "dur": 1.0}]
```
