## 二、技术实现概览

### 2.1 数据流转

```
简谱文本 "1 0 2"
    ↓ parse_jianpu()
[{"notes": ["mid_1"], "dur": 1.0},
 {"notes": [], "dur": 1.0},          ← 休止符
 {"notes": ["mid_2"], "dur": 1.0}]
    ↓ from_storage()
[IRNote(...), IRRest(dur=1.0), IRNote(...)]
    ↓ compile_score()
时间轴推进 (cursor += dur * beat_ms)
    ↓ Player.play()
实际停顿 (通过绝对时钟自动处理)
```

### 2.2 关键特性

1. **精确计时**: 绝对时钟调度,无累积误差
2. **修饰键释放**: 休止符前自动释放高低八度键
3. **时值灵活**: 支持 0.0625~16 拍(六十四分音符~四全音符)
4. **向后兼容**: 旧版本数据库无需迁移

## 七、常见问题

### Q: 为什么说"无需集成"?

**A**: 代码审查和测试结果显示,休止符功能在以下环节已完整实现:
1. Parser: 能识别 `0` 及其时值后缀
2. IR: 定义了 `IRRest` 类并正确转换
3. Compiler: 编译为时间间隔,自动释放修饰键
4. Player: 通过绝对时钟自动处理停顿
5. GUI: 校对表格正确显示

### Q: 安卓端和桌面端的区别?

**A**: 两者共享相同的核心模块(`core/`),休止符逻辑完全一致:
- 桌面端: Python 键盘驱动
- 安卓端: Kotlin 手势注入
- 共享: Parser、IR、Compiler 逻辑

### Q: 如何验证我的版本有休止符功能?
