## 0. 前置事实（集成前必读）

- 道具正式名**守夜人口琴**：2 格红色藏品，可带入对局、局内手持自由吹奏；右下角另有**自动演奏**（初始送 2 首谱，NPC"风声未止"任务再解锁 4 首，共 6 首）。[S6][S10][S12] **可信度：高**
- 存在两套场景，**输入模型一致**：① 局内自由演奏；② NPC 听旋律复刻任务（PC 屏幕下方提示英文字母、手游提示数字，按完 **Q 提交**）。[S10] **可信度：高**（界面截图为自由演奏态，任务态有多篇视频佐证）
- 媒体描述其"**8 度音阶齐全、可升降调**"。[S13] **可信度：中**（单一文字来源，但与界面/操作证据一致）

## 1. 按键映射：完整「按键 → 音高」表

### 1.1 PC 默认键位

界面每格 = **大数字（简谱音名）+ 小字母（PC 按键）**，从左到右 7 个自然音 + 右侧延续的高音格。

| 简谱音名 | 唱名 | PC 自然音键 | 降调（按住左键） | 半音（按住中键/滚轮） | 升调（按住右键） |
|---|---|---|---|---|---|
| 1 | do | **Z** | 低音1（Z+左键） | #1（Z+中键） | 高音1（Z+右键） |
| 2 | re | **X** | 低音2 | #2 | 高音2（X+右键） |
| 3 | mi | **C** | 低音3 | #3（=4 等音） | 高音3 |
| 4 | fa | **V** | 低音4 | #4 | 高音4 |
| 5 | sol | **B** | 低音5 | #5 | 高音5 |
| 6 | la | **N** | 低音6 | #6 | 高音6 |
| 7 | si | **M** | 低音7 | #7（=高音1 等音） | 高音7 |
| 高音1（ī） | do' | **,（逗号）** 物理直达，免右键 [S4] | — | — | 等价于 Z+右键 |
| 高音2（ré） | re' | **.（句号）** 仅 1 个来源，见冲突② | — | — | 等价于 X+右键 |
| 高音3（mī） | mi' | **/（斜杠）？待确认** | — | — | 等价于 C+右键 |

- **自然音行 Z X C V B N M = 1 2 3 4 5 6 7**：由界面实拍 [S1] 锁定，并被 4 首隐藏乐谱的"端游字母串 ↔ 手游数字串"逐音互证。
  - 例 1：老乔 `BZXCBVCZXC` = 降调 `5123543123`，逐位对应 B=5 / Z=1 / X=2 / C=3 / V=4。
  - 例 2：佐拉 `MNMN` = 自然音 `7676`，即 M=7 / N=6。
  - [S2][S3][S5][S7] **可信度：高**
- **鼠标三修饰态**：左键=降调（低音区）、中键（滚轮按下）=半音（当前音升半音）、右键=升调（高音区）——界面下方三个按钮直接画了左/中/右鼠标图标并标注"降调/半音/升调"[S1]；B站谱例图例写作"（）低音区鼠标左键、#升半音鼠标中键、【】高音区鼠标右键"[S2]。**可信度：高**
- **逗号键直达高音1**：教程原文"上面有点的字母需要按住右键，**也可以直接按 M 旁右边的逗号那个键**，带井号的字母需要按住鼠标中键"[S4]，与界面第 8 格显示高音 `ī` 互相吻合。**可信度：中高**
- **实际物理音高（1 是否 = C、具体频率）无任何来源** → **待确认**；模块建议先用"简谱音级 + 八度枚举"建模，不要写死 C/D/E 音名。

### 1.2 手游映射

- 界面为 **1–7 数字音格 + 下方"降调 / 半音 / 升调"三个状态钮**；数字即简谱音名，状态钮按住选择音区，与 PC 一一对应（所有隐藏谱均给出"PC 字母串 / 手游数字串"双版本且完全对得上）。[S3][S5][S8] **可信度：高**
- 状态钮是"按住生效"还是"点一下切换"：教程措辞为"按住下面写的按键，升调还是降调……去操作"[S8]，倾向按住态，但无实测 → **待确认（低风险）**

## 2. 出声机制：点按 / 长按 / 拖动 / 连按 / 和弦

| 操作 | 实际效果 | 依据 | 可信度 |
|---|---|---|---|
| **点按** | 触发**一个单音**，默认短音长（具体秒数无数据，**待确认**）；规则原文"**未标注均单点一下即可，无论有无声音不要多点**"（转引自 B站 ADFLS 解密帖） | [S9] | 高 |
| **长按** | **延音/长音**，声音持续到松开，时长=按压时长；任务中长音要求按住约 2–3 秒（"最后一个6长按二三秒"）；谱面上两个相同音连写等价于一次长按（"767(66长按)……实际操作中直接长按即可"） | [S5][S9][S11] | 高 |
| **按住拖动** | **无任何来源记载**；界面是离散音格，没有滑条/滑音面，**倾向不支持滑音/弯音**，自由演奏下仍需实测确认 | 无 | 低（待确认） |
| **连按/狂按** | 不存在独立的"连音/颤音"触发态：**每按一次重新触发一个同音**；任务场景明确禁止多点（多按=多出音符→识别失败） | [S9] | 中高（结论主要来自任务场景） |
| **和弦（多音同响）** | **无证据支持**。整体是单旋律乐器模型；"鼠标修饰键 + 音键"是改音高不是和弦；两个字母键同时按下的抢占/叠加规则 → **待确认，倾向单音、后按覆盖** | 无 | 低 |
| 自动演奏 | 右下角入口，对已解锁谱面自动播放，无需输入 | [S10] | 高 |

> **集成提示**：输入层至少需要 `press / release` 两个事件（长按依赖释放时机），而非只有"点击"事件；时值由按下时长决定，没有独立的延音踏板/保持按钮。

## 3. 音区切换：低音 / 中音 / 高音怎么换

**结论：不是音阶切换键、不是翻页、不是八度键、更不是现实口琴的"吹/吸"配合，而是"修饰键按住态"模型。** [S1][S2][S8] **可信度：高**

- **中音（自然音）**：不按任何鼠标修饰，直接敲 Z–M。
- **低音（降调）**：**按住鼠标左键期间**，所敲音格整体落入低八度区；松开左键即回自然音。谱例标记为"降调 / ( ) / 字母下点"。
- **半音（chromatic）**：**按住鼠标中键（滚轮按下）期间**，所敲音升半音（提供黑键音，如 #3=4、#5 等）；谱例标记为 `#`。
- **高音（升调）**：**按住鼠标右键期间**整体进入高八度区，松开回自然音；谱例标记为"升调 / 【】 / 字母上点"。PC 另有 **, . / 物理键直达高音**的替代路径（见 1.1）。
- **修饰态是"持续生效的按住状态（latch-while-held）"，影响期间所有后续音**：教程操作序列可直接证明——风起："**按住**左键 NM，**松手** ZXZ，再**按住**左键 M，**松手** Z"[S3][S5]；若不松手，后面的音会一直被带在低/高音区。**可信度：高**
- 三种修饰态能否互相叠加（如"左键+中键 = 低八度半音"）、升/降是否严格为一个八度：**待确认**（"8度音阶"描述 [S13] 仅支持单八度平移这一层）。

## 4. 键位排列规则 + 「按住 vs 点按」实际差异

### 4.1 排列规则（可直接用于模块建模）

- **二维结构 = 7 个音位 × 4 种状态**：音位由键盘**最底排从左到右** Z X C V B N M 排布，音高严格**从左到右上行**，等价钢琴白键 1→7；状态由鼠标三键选择 自然 / 降 / 半音 / 升。[S1][S2] **可信度：高**
- 底排继续向右的标点键 **, . /** 是同一上行序列在高音区的物理延伸（, = 高音1 已证实，. / 待确认）；**左侧没有任何键，故低音没有物理直达键，只能按住左键**。[S4] **可信度：中**
- 手游为同构的 1–7 数字格 + 三状态钮。[S1]
- 顶部数字行 1–7 是否也能敲出发声：仅 1 条调侃式教程暗示（"把数字键键帽扣到字母排"）[S14]，**待确认**；界面上的大数字是简谱标注而非明确的第二绑定。

### 4.2 按住 vs 点按差异（集成要点）

| 维度 | 点按 | 长按（按住） |
|---|---|---|
| 时长 | 固定短音，时值不可控 | 时长完全由按压持续时间决定，松开即收音 |
| 延音 | 无 | 有，且是唯一的延音/长音手段 |
| 断连 | 音与音之间需抬起再按下；多按会多生成音符（"不要多点"）[S9] | 一个长按可替代两个同音连写；中途不抬键不会产生第二个音 [S11] |
| 对后续音影响 | **音键本身**：不影响，松开即结束 | **鼠标修饰键**：不松开则后续每个音都被转调，必须显式"松手"才回自然音 [S3][S5] |
| 任务判定 | 只校验**音高序列**，不卡节奏（"不用数拍子/不需要懂音乐"）[S3][S12] | 长音位置必须真的长按（约 2–3 秒），否则判定失败 [S5][S11] |

## 5. 多来源冲突并列（不替实现方拍板的部分）

1. **自然音行是否含 4**：抖音《花海》谱称"zxcvbnm. = 123567(高音1高音2)"，即 V=5、跳过 4、M=高音1 [S15]；但界面实拍 [S1] 与至少 6 篇隐藏乐谱互证均为 **V=4、B=5、N=6、M=7**。判断：该作者按《花海》五声音阶用到的音顺序"对号入座"造成错位标注。**采信后者**，保留差异供复核。
2. **佐拉曲目中段是"自然音354"还是"半音354/半音243"**：多数通关谱为自然音 3 5 4（中键 CBV 的按法与自然音按法均有人用）；早期解密帖给过"半音354"，另有"半音243"备选，且作者自注"半音通过的很少"。[S5][S9][S11] → 任务识别对该段似有容错，**集成时半音通道仍需保留，但不要把 354 写成死规则**。
3. **龙启电竞谱中出现"按住右键 C F C F"** [S5]：F 不在底排音位上，其余所有来源均无 F 键。判断为口误/字幕错误（疑为 V 或相邻键），**孤证不采信，列待确认**。
4. **道具命名**：游戏内藏品界面为"守夜人口琴"，大量攻略叫"口风琴"[S1][S6]，检索时两个关键词都要用。

## 9. 一句话建模总览

```
音位(Z–M = 1–7，, . / = 高音延伸)
  × 状态(自然 / 左键·降调 / 中键·半音 / 右键·升调，均为"按住态")
  + 点按=短单音、长按=按时长延音
  + 无拖动/连按/和弦机制（待实测）
任务校验：只认音高序列与长音位置，不认节奏。
```
