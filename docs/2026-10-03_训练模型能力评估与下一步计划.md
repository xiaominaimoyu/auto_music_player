# 训练模型能力评估与下一步计划

评估日期：2026-10-03。范围：已保存的两套全量 MLP checkpoint、PianoCoRe v2 数据、现有训练/评估实现、150 条历史 pilot 受控消融、本轮 18/4 质量 sidecar 诊断 pilot，以及 P1 的 500 条来源抽检、v2/v3 三 seed 配对实验；不修改播放器和 Android。采用通用技术报告结构，未使用安全报告厂商模板。

## 结论

训练链路和推理链路可运行；模型确实学到了一部分力度与谱面特征的关系。按计划完成了来源标签抽检、评估器固化和 pilot 消融，但当前模型尚未通过游戏演奏接入条件：按键时长退化、微偏移弱于原谱、长窗口节奏漂移增加。建议保留全量 checkpoint 作为研究基线，先处理数据与训练方法，再进行序列模型实验。

本轮已完成 12 个来源审计标记样本的二次只读复核，校准了 sidecar 规则，并把 sidecar 作为显式训练选项接入；随后扩展到每来源 100 条演奏抽检、147 条标记候选、v2/v3 各 3 个 seed 的 244/24 配对 pilot。两轮结果均不支持质量 mask 接入后的全量重训，下一步转向标签/tempo 条件和序列建模，不能把 pilot 的局部变化当作泛化收益。

上轮“最佳研究候选”指混合验证损失最低，不等于演奏效果最佳。上轮 test 结果已经影响后续实验方向，因此现有 test 应标记为已接触的研究评估集；不得再宣称它是完全未接触的最终盲测集。checkpoint 的 epoch 选择确实来自 validation，但这不消除实验层面的 test 接触。

## 逐目标能力

以下为本次独立重测，MAE 越低越好。“均值”仅使用 train 统计。“原谱”对 micro offset/onset 取零、对 duration/IOI 的 log ratio 取零，即保持比例 1；后者是数据定义中的整体速度归一化原谱，并非用户指定的绝对 BPM 基线。log ratio 误差不能当作毫秒或百分比。

|---|---:|---:|---:|---:|---|
| 力度，0–1 | 0.11441 | 不适用 | 0.10440 | 0.10370 | 比均值改善 9.4%，有实际学习信号 |
| 相对力度 z | 0.57234 | 不适用 | 0.52784 | 0.52897 | 有提升，基础模型此项略好 |
| 按键时长 log ratio | 0.78248 | 0.79195 | 0.92974 | 0.92017 | 比均值差 17.6%，不宜接入 |
| 和弦内微偏移，ms | 7.93247 | 7.75328 | 7.91370 | 7.90928 | 比原谱差约 2.0% |
| IOI log ratio | 0.26921 | 0.27211 | 0.26715 | 0.26728 | 比均值仅改善约 0.72% |
| 有界 onset 辅助偏差，ms | 819.756 | 821.197 | 819.156 | 818.828 | 比均值仅改善约 0.11% |
| 踏板起始值，0–1 | 0.43139 | 不适用 | 0.37109 | 0.37714 | MAE 降低，但 RMSE 变差 |
| 踏板覆盖率 | 0.35997 | 不适用 | 0.31439 | 0.31562 | MAE 降低，但 RMSE 变差 |

正则化力度相关系数约 0.382，R² 约 0.144；并不是精确恢复真人力度。其 IOI 相关系数约 0.121、R² 约 0.010，预测标准差 0.0359，真实标签标准差 0.3954：输出变化幅度约为标签的 9.1%，有明显向平均值收缩的迹象。微偏移相关系数仅约 0.029。

时长 log ratio 的平均有符号误差为 -0.5831，提示系统性低估键时长，不能只看总 loss。踏板起始值 RMSE 为 0.47431，而均值基线为 0.45714；覆盖率 RMSE 为 0.41458，而均值基线为 0.40691。踏板相关系数仅约 0.06，因此 MAE 改善不能被解释为学会完整踏板控制。

正则化模型时长误差的全域抽样 p95 约 2.2855，旧 evaluator 输出约 1.5484；旧代码只保留排序最前面的 20 万误差，不能代表全域 p95。本次 MAE 与上轮对应数值吻合，差异集中在旧分位数采样方法。

上次全量正式 evaluator 以 11,922 个演奏样本作为 bootstrap 单位，得到正则化模型时长 log ratio `0.9355`（95% CI `0.9294–0.9414`）、原谱基线 `0.7714`（`0.7675–0.7757`）；微偏移模型 `8.4293 ms`（`8.3600–8.5086`）、原谱 `8.2384 ms`（`8.1561–8.3141`）；IOI 模型 `0.2537`（`0.2519–0.2554`）、原谱 `0.2591`（`0.2573–0.2608`）。这些是历史演奏样本级结果，不能继续称为作品级 CI。

修正聚合键后，使用正则化 checkpoint 在 full validation（9,667 条演奏、317 个 `performance_dataset::piece_group` 作品单元）重跑：作品等权 duration log ratio 为模型 `0.6823`（95% CI `0.6592–0.7051`），原谱 `0.6282`（`0.6032–0.6585`）；微偏移模型 `7.0048 ms`（`6.6245–7.4125`），原谱 `6.6916 ms`（`6.3007–7.0888`）；IOI 模型 `0.1739`（`0.1638–0.1839`），原谱 `0.1769`（`0.1671–0.1877`）；velocity robust-z 模型 `0.5305`（`0.5221–0.5392`），均值基线 `0.5777`（`0.5730–0.5825`）。这确认了作品级统计口径已生效，但 validation 仍显示时长/微偏移未优于原谱，不能据此启动全量质量 mask 重训；该结果不是最终 test/盲测。

上轮综合 test loss：基础 0.38295、正则化 0.38115、均值约 0.39126，仅作历史参考。本次未重算该混合损失；上轮均值还采用了不同的分片聚合方式，不能把三者差值当作严格的同口径显著收益。后续应统一按目标和有效权重累积损失。

### P1 第二轮：保守 v3 目标级降权

v3 保持同一 147 条候选、244 个 train 与 24 个 validation 样本，以及同一网络、优化器、5 epoch 预算；只改变低对齐标记的目标作用范围。低对齐仅将 micro-offset、duration、onset 辅助和 IOI 设为 0.5，velocity 不再因低对齐连带降权，pedal 仅在独立的 CC64 尾音证据触发时降权。v3 sidecar 仍保留原生逐事件 mask，硬禁用为 0。

三个 seed 的 validation loss（v3 软 mask 减无 mask）为：`+0.000349`（20261003）、`-0.000231`（20261004）、`+0.000084`（20261005），方向仍不一致。24 条 validation ID 中仍有 23 个作品单元可成对比较；以下为跨 seed、按作品取均值后 2,000 次 paired bootstrap，正值表示误差变差：

## 工程可运行性与当前限制

两套模型全部 test 输出均为有限数。时长和 IOI 比例取 exp 后未出现非正数/非有限值，且全部落在 0.25–4 范围内。这个范围检查是数值诊断，不代表游戏支持这些按键长度或音符间隔。

正则化模型在有监督踏板标签上的起始值越界比例约 0.0862%，覆盖率越界约 0.00367%，说明裸输出缺少范围保证。正式导出前须添加合法范围、最小 IOI、最短按键、重叠与重复音约束。

基础模型 38,152 参数；正则化模型 141,832 参数。CPU 四线程处理 2,048 个 note 的中位延迟约为 0.59/1.30 ms，p95 约 1.39/1.64 ms。此计时仅含预热后的 note head 前向计算，不含 MIDI 解析、特征构建、文件读写、chord head、模型加载、键盘调度与打包环境。模型运算本身不是当前主要障碍。

当前架构是 note/chord 独立 MLP，没有序列记忆、乐句规划、明确声部身份或完整 CC64 曲线；力度/踏板也尚不能由当前游戏键盘通道直接输出。验证集输入打乱诊断对力度影响明显，对节奏目标影响较小，和全量相关性结果相符，但这不能替代 target-shuffle 重新训练负对照。

## 过拟合、欠拟合的判断

正则化模型 validation loss 在 epoch 3 达到 0.39072，epoch 4/5 回升到 0.39213/0.39207，而 train loss 持续下降：存在后期泛化回落迹象，保留 epoch 3 合理。基础模型到 epoch 5 验证仍改善，不能断言所有模型都已严重过拟合。

时序目标预测变化很小、相关性低，可能涉及上下文不足、目标噪声或输入尺度问题。训练代码直接输入绝对 `score_onset_beats`，仅规范化目标，长曲位置可能压制其他局部特征；每轮固定按来源/分片顺序，只在片内打乱，可能产生来源顺序偏差。这些是代码证据支持的候选原因，尚无消融结果，不能确定因果。正则化试验同时改变容量、学习率、dropout、weight decay，也不能把收益单独归因于 dropout。

因此下一步优先诊断标签与训练方法；单纯增加 epoch 或扩大模型并非证据支持的首选。
